# Manual Técnico - Smartphone MultiTech X1

## Especificações Técnicas
- Tela: 6.7 polegadas AMOLED 120Hz
- Processador: Octa-core 3.2GHz
- RAM: 12GB
- Armazenamento: 256GB (expansível até 1TB)
- Bateria: 5000mAh com carregamento rápido 65W
- Câmera principal: 108MP com estabilização óptica
- Câmera frontal: 32MP
- Sistema operacional: Android 14
- Resistência: IP68 (água e poeira)

## Problemas Comuns e Soluções

### Câmera com Defeito
- Sintoma: fotos borradas ou câmera não abre
- Solução 1: reinicie o dispositivo
- Solução 2: limpe o cache do aplicativo de câmera
- Solução 3: verifique se há atualização de software pendente
- Solução 4: se persistir, acionar garantia

### Bateria não Carrega
- Verifique se o cabo e o carregador são originais
- Limpe a porta de carregamento com ar comprimido
- Tente carregamento sem fio se disponível
- Se não resolver, acionar assistência técnica

### Superaquecimento
- Evite uso intenso por períodos prolongados
- Não exponha o aparelho ao sol diretamente
- Feche aplicativos em segundo plano
- Se persistir acima de 45°C, acionar garantia

### Tela não Responde
- Reinicie o dispositivo
- Verifique se a película protetora está interferindo
- Execute restauração de fábrica como último recurso

## Garantia
- Prazo: 12 meses para defeitos de fabricação
- Não cobre: danos físicos, líquidos ou mau uso
- Acionamento: suporte@multitech.com.br ou 0800 123 4567

## Atualizações de Software
- Mantenha o sistema sempre atualizado
- Atualizações disponíveis em: Configurações → Sistema → Atualização
